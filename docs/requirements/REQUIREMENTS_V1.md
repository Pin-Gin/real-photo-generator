# real-photo-generator — 開発要件 v1

**要件状態:** 2026-11-24 のユーザー確定事項。技術選定・品質達成は未確認。
**リポジトリ:** `Pin-Gin/real-photo-generator`（旧 `local-image-generator` から独立）
**構成資料:** [`../architecture/D_DRIVE_LAYOUT.md`](../architecture/D_DRIVE_LAYOUT.md)

## 1. 目的

ローカル環境で、ユーザー提示画像と同水準を目標とした、オリジナル成人女性の**高品質なセミリアルCG〜フォトリアル寄り**画像を自在に生成する。将来はMaster参照＋自然文指示による画像生成、Master／入力画像からの動画生成を実装する。

- **純粋な実写写真のみを正解にしない。** セミリアルCGの整った顔、なめらかな肌、自然な立体感、場面に応じた艶・濡れ表現も許容する。
- **従来の平面的なアニメ調とは区別する。** 旧アニメ専用のMatte設定やCGI/PBR一律禁止ルールを自動継承しない。
- **GPT並の品質**は目標であり、実現済みの事実ではない。比較基準はユーザー提示のプールサイド、サウナ等の画質見本。
- 個別の顔・髪・体格を固定する**人物Master**と、場面の画風／品質を示す**スタイル参照**は区別する。画像の採用や同一人物判定を勝手に確定しない。

## 2. 開発順序（変更しない）

### Phase 0 — クリーンな環境再構築

- 旧アニメ用Gitと実験コードを新環境へそのまま流用しない。
- ユーザー作成の新Git `Pin-Gin/real-photo-generator` を D ドライブにcloneする。
- ダウンロード済みモデル・アプリは使える可能性があるためファイル一覧と必要な実体コピー／ハッシュを保全する。棚卸しCSVはバックアップそのものではない。
- 旧データや旧リポジトリを削除する前に、必要な参照画像・モデル・アプリを照合する。削除は自動化しない。

### Phase 1 — テキストのみの画像生成モデル選定・品質検証

- 先に**セミリアルCG〜フォトリアル寄りの成人女性**生成に長けたモデルを調査・比較する。
- RTX 5080・16GB VRAM、Windows、ローカル実行、モデル利用条件、コスト、速度などを確認する。
- **Master画像をまだ使わず文章だけ**で複数回生成し、顔／髪／肌／身体構造／指や手足／立体感／光／背景との整合／安定性を目視評価する。
- モデル採否や品質の合格はユーザー判断による。事前に架空の合格数値を決めない。

### Phase 2 — Master画像＋文章での自在な画像生成

- Phase 1でユーザーが品質を承認した後、指定の女性を対象とする写実寄りMasterを検証・承認する。
- Masterの顔・髪・体格などの同一人物性を保ち、衣装／表情／ポーズ／構図／背景を自然文で変更できるようにする。
- 画質と同一人物性を別々に評価する。
- 最初はテキスト入力、**将来的にはチャット形式の入力**も目指す。

### Phase 3 — 動画生成

- **Master画像＋動作文章**で動かす。
- **入力画像の内容を解釈して動きを生成する**Image-to-Videoにも対応したい。
- 最終出力の**60FPSを目標**とする。ただしモデルによるネイティブ60FPS生成を保証する意味ではなく、補間等の採否は検証後に決める。
- 被写体の同一性、フレーム間の揺れ、自然な動作、尺、解像度、必要VRAM、生成時間、補間後の品質を個別に検証する。
- 静止画と動画に同じモデルを採用する前提は置かない。

### Phase 4 — ツール化

- 画像・動画の生成品質を検証してからアプリ化する。
- **Webアプリ／デスクトップアプリは現時点で未選定**。生成バックエンドをUIから切り離す。

## 3. 検証・安全境界

- 旧Git・旧検証コード・旧モデル重み・私的参照画像・生成物を新Gitに一括投入しない。
- Qwen/FLUX/SDXL等は旧環境で名前が確認できた候補にすぎず、今回の正式採用モデルは未定。
- 参照画像の実ファイルパスや合格基準の数値は現時点で未確定。推測で埋めない。
- Dドライブのフォルダ骨格を作ることと、実行可能な画像生成環境の構築は別の作業。
